# .github

Organization meta-repository for [**cook-gpt**](https://github.com/cook-gpt) — governance, automation, and the public org profile for **CookGPT**.

**CookGPT** is a native SwiftUI app for iPhone and iPad: recipes, meal planning, grocery lists, and step timers with Live Activities while you cook.

## Organization profile

The visitor-facing page at [github.com/cook-gpt](https://github.com/cook-gpt) is rendered from [`profile/README.md`](profile/README.md).

## Repositories

| Repository | Summary |
|------------|---------|
| [**.github**](https://github.com/cook-gpt/.github) | Public organization meta-repository (profile, governance, and automation) |

The CookGPT application is developed in a **private** repository. The public org page is [github.com/cook-gpt](https://github.com/cook-gpt).
