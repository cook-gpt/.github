# Purpose

Hosts the [**`.github`**](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) meta-repository for the [**cook-gpt**](https://github.com/cook-gpt) organization.

| Deliverable | Role |
|-------------|------|
| [`profile/README.md`](../../profile/README.md) | **Public** organization profile at [github.com/cook-gpt](https://github.com/cook-gpt) |
| Root governance docs | `README`, `INSTRUCTIONS`, `CHANGELOG` for maintainers |
| `.github/` automation | Dependabot, CODEOWNERS, issue/PR templates |

The CookGPT app is developed in a **private** repository. Public visitors use [github.com/cook-gpt](https://github.com/cook-gpt) and this **`.github`** repo only.
